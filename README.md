# Bangladesh Donate Now

Bangladesh Donate Now is a web-based project aimed at encouraging and facilitating donations to support various causes in Bangladesh. The application features a user-friendly interface, responsive design, and seamless functionality to ensure a smooth donation experience.

## Project Overview
This project allows users to contribute to various causes, such as education, health, and disaster relief. It displays real-time progress on fundraising goals, ensuring transparency and engagement. The application leverages modern web technologies for performance and responsiveness.

## Main Technologies Used
- **HTML**: For the structure of the application.
- **Tailwind CSS**: For modern and responsive styling.
- **JavaScript**: For dynamic interactivity and functionality.

## Features
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Blog Page**: Informative blog section to keep users updated on donation efforts.
- **History Section**: View previous donations and their impact.
- **Donate Now Button**: Simple and intuitive call-to-action for users to contribute.

## Dependencies
- Tailwind CSS (CDN)
- Font Awesome (for icons)
